# Collabor·ate

> The modern creator-brand collaboration platform.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Pages

| Route | Page |
|---|---|
| `/` | Landing page |
| `/auth/login` | Login |
| `/auth/signup` | Signup |
| `/onboarding` | Creator onboarding |
| `/dashboard/influencer` | Influencer dashboard |
| `/dashboard/brand` | Brand dashboard |
| `/dashboard/brand/discovery` | Creator discovery |
| `/dashboard/brand/campaigns` | Campaign management |
| `/dashboard/brand/messages` | Messages |

## Tech stack

- **Next.js 14** — App Router
- **TypeScript** — Type safety
- **Tailwind CSS** — Styling
- **Framer Motion** — Animations
- **Lucide React** — Icons
- **Recharts** — Analytics charts

## Features

- Custom cursor with lag effect
- Scroll-triggered reveal animations
- Magnetic button effect on CTAs
- Animated stat counters
- Spring-physics toggles
- Floating hero cards
- Full creator & brand dashboards
- In-app messaging
- Campaign management
- Creator discovery with filters
